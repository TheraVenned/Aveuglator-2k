Aveuglator 2000

Arrêt

FPS 0.0 INF 0 ms TOT 0 ms
caméra PROF 0–0

Tenez le téléphone à la verticale, caméra vers l'avant, à hauteur de poitrine, puis appuyez sur Démarrer. Montez le volume : les obstacles sont signalés par des sons.

Prêt

moteur non chargé

Réglages

Retours

Vision

Ombres : le lointain est blanc, ce qui est proche apparaît sombre. Fausses couleurs : rouge = proche, bleu = loin.

Détection

Référence proche : valeur brute du modèle tenue pour « très proche ». À 0, la profondeur est normalisée image par image. Relevez la valeur haute de « PROF » face à un obstacle à environ un mètre pour la calibrer.

Système

WebGPU peut accélérer nettement l'analyse sur les téléphones récents. La page se recharge au changement ; en cas d'échec, le moteur standard reprend la main.
